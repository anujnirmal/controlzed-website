# Controlzed Labs

Dark neon redesign concept for Controlzed Labs, built with Next.js App Router and Tailwind CSS 4.

## Run locally

Install dependencies with `npm install`, then start the development server with `npm run dev`.

## Pages

- `/` — agency landing page with capabilities, client list, process story, projects, founder feature and contact details
- `/work/mysaathi`
- `/work/karma-kundli`
- `/work/unycc`
